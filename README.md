<h1>Central de Pacientes</h1>

Sistema de gestión de pacientes desarrollado en Java utilizando listas simplemente enlazadas. Permite registrar, buscar, eliminar y mostrar pacientes atendidos en distintas clínicas de la ciudad. 
Este proyecto se desarrollo utilizando el lenguaje programacion orienteda a objetos (Java), manejamos estructuras de datos con listas simplemente enlazadas.

Características:

- Registro de pacientes con ID único, nombre, edad y clínica.
- Búsqueda de pacientes por ID.
- Eliminación de pacientes registrados.
- Visualización de la lista completa de pacientes.
- Implementación con listas enlazadas para optimizar la gestión de datos.
