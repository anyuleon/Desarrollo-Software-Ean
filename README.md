<h1>Evaluador de Expresiones Aritméticas</h1>

Este proyecto en Java permite evaluar expresiones aritméticas ingresadas en notación infija. Utiliza una pila para convertir la expresión a notación postfija (Polaca Inversa) y luego evaluarla.

Funcionalidades:

- Verificación de paréntesis balanceados en la expresión.
- Conversión de notación infija a postfija usando una pila.
- Evaluación de la expresión postfija para obtener el resultado final.
- Interfaz en consola para la interacción con el usuario.

Este programa aplica estructuras de datos y el concepto de Pilas para manejar la jerarquía de operadores y realizar la evaluación correctamente.
