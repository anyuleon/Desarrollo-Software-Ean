

<h1>Cálculo de Impuestos Vehiculares - Java Swing</h1>


Este proyecto es una aplicación desarrollada en Java Swing utilizando el patrón Modelo-Vista-Controlador (MVC). Permite calcular el impuesto vehicular en función del avalúo comercial, tipo de uso y normativa vigente.

🚀 Características:
Interfaz amigable para el ingreso de datos.<br>
Cálculo automático según rangos establecidos:<br>
- Hasta $55.679.000: 1.5%<br>
- $55.679.000 - $125.274.000: 2.5%<br>
- Más de $125.274.000: 3.5%<br>

Exención para vehículos públicos, mostrando un mensaje basado en la Ley 488 de 1998, artículo 141.<br>
🔹 Tecnologías: Java, Swing, MVC.<br>
🔹 Estructura:<br>
📂 model/ → Lógica de negocio
📂 view/ → Interfaz gráfica
📂 controller/ → Conexión entre vista y modelo

💻 Ejecución
Compila y ejecuta Main.java para iniciar la aplicación.
