<h1>📦Sistema de Gestión Logística (TechLogistics)</h1>

🚀 Sistema full-stack para gestión y seguimiento de envíos, desarrollado como proyecto de aprendizaje en:

✔ Bases de datos relacionales (MySQL)<br>
✔ APIs REST (Node.js/Express)<br>
✔ Frontend dinámico (React)<br>


<h1>🛠 Tecnologías</h1>
✔ Área	Tecnologías<br>
✔ Base de Datos	MySQL, XAMPP<br>
✔ Backend	Node.js, Express, Axios<br>
✔ Frontend	React, CSS3, React Router<br>
✔ Control Versión	Git/GitHub
